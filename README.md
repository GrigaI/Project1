Настройка в Visual Studio

Create a new project → Empty Project (C++) — не бери "Console App", чтобы самому добавить .cpp и увидеть, как всё собирается.

Правый клик по проекту → Add → New Item → C++ File (main.cpp).

Свойства проекта → C/C++ → Language → C++ Language Standard → ISO C++20.

Убедись, что конфигурация — x64 / Debug.

Проект: «Консольный менеджер задач» (To-Do)

Почему именно он: это CRUD-приложение, на котором удобно отрабатывать всё — от структур и указателей до STL-контейнеров, файлового ввода-вывода, полиморфизма и RAII. Каждый этап добавляет ровно одну новую тему.


Этап 1. Разминка: ввод-вывод и управление потоком

Меню в консоли (switch, цикл while).

Команды: добавить задачу, показать список, удалить по индексу, выход.

Хранение — std::vector<std::string>.

Цель: вспомнить std::cin/cout, getline, циклы, фу
нкции.

Этап 2. ООП: классы

Появляется struct Task { int id; std::string title; bool done; }.

Класс TaskManager с методами add(), remove(), list(), toggleDone().

Инкапсуляция: поля private, публичный интерфейс.

Цель: конструкторы, this, константные методы, разделение на .h
/.cpp.

Этап 3. STL и файлы

Задачи грузятся/сохраняются в tasks.txt или tasks.json (JSON — вручную, без библиотек).

std::find_if, std::remove_if, std::sort с лямбдой (сортировка по дате/статусу).

Цель: итераторы, алгоритмы, fstream, работа с ошибками через std::optional/std::expec
ted.

Этап 4. Наследование и полиморфизм

Задачи разных типов: RegularTask, DeadlineTask, RecurringTask.

Базовый класс Task с virtual std::string describe() const.

Хранение через std::vector<std::unique_ptr<Task>>.

Цель: виртуальные функции, виртуальный деструктор, полиморфное уда
ление.

Этап 5. RAII и умные указатели

Оберни работу с файлом в класс FileGuard (открывает в конструкторе, закрывает в деструкторе).

Замени «сырые» указатели на unique_ptr/shared_ptr там, где это уместно.

Цель: вспомнить правило трёх/пяти, copy/move-конструкт
оры.

Этап 6. Шаблоны и современный C++

Обобщённый Repository<T> для хранения задач.

Перегрузка операторов (operator<< для вывода задачи).

std::format (C++20) вместо printf/<<.

Цель: шаблоны, концепты (по желанию), r
anges.

Этап 7 (со звёздочкой). Тесты и сборка

Подключи GoogleTest через NuGet → покрыть TaskManager тестами.

Попробуй CMake вместо встроенной системы проектов V
S.

Полезные привычки с первого дня

Включи /W4 (Warning Level 4) и Treat Warnings as Errors — сразу отучит от грязного кода.

Запускай Debug + ASan (AddressSanitizer: Properties → C/C++ → General) — быстро ловит утечки и выход за границы.

Коммить каждый этап в git — увидишь эволю
цию.
